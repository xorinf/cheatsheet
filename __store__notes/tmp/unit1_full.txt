Department of Defense developed a communication network known as ARPANET (Advanced 
Research Projects Agency Network).  The objective of ARPANET was to establish a 
communication system that could continue functioning even if some communication links 
failed. Later, universities and research organizations joined these networks.  This development 
led to the creation of the modern Internet.

5. HTML ELEMENTS  
Every webpage available on the World Wide Web is made up of different types of 
content such as headings, paragraphs, images, hyperlinks, tables, forms, and multimedia. 
Although these contents appear differently on the screen, a web browser cannot identify 
their purpose unless they are represented using HTML elements. HTML elements provide the 
structure and meaning required for the browser to interpret and display webpage content 
correctly. For this reason, HTML elements are considered the fundamental buildi ng blocks 
of every webpage.  
 
When a user opens a college website, the browser automatically displays the college name 
as a heading, admission details as paragraphs, navigation options as hyperlinks, and images 
in appropriate locations. This is possible because each piece of informatio n is enclosed within 
a suitable HTML element.  
 
5.2 Need for HTML Elements  
A browser processes only instructions written in HTML. If a webpage contains only plain 
text, the browser cannot distinguish between a heading, a paragraph, or a hyperlink. HTML 
elements solve this problem by defining the purpose of each content item. They  organize 
the webpage into meaningful sections, improve readability, support accessibility, and help 
search engines understand webpage content.  
 
For example, consider a college admission webpage. The college name should appear larger 
than the remaining text, admission details should be displayed as paragraphs, and the 
online application option should be presented as a clickable link. HTML elements enable the 
browser to display all these contents appropriately.  
 
Example: 
A university is designing its admission portal. The homepage must display the university 
name, admission notification, and an "Apply Online" link. Without HTML elements, the 
browser cannot identify which content is the title and which content should functi on as a 
hyperlink. By using appropriate HTML elements, the webpage becomes structured, readable, 
and user-friendly. 
 
5.3 Definition of HTML Element  
An HTML element is a complete unit of an HTML document that consists of an opening 
tag, content, and a closing tag, representing a specific part of a webpage.  
 
Syntax 
<tagname>Content</tagname>  
 
Example 
<p>Welcome Students</p>

Opening Tag: <p> 
Content: Welcome Students  
Closing Tag: </p> 
 
The complete structure <p>Welcome Students</p> is called an HTML element . 
It is important to understand that the browser reads the complete element rather than the 
content alone. The tags specify the type of content, while the enclosed text represents the 
information displayed to the user.  
 
5.4 Structure of an HTML Element  
A standard HTML element consists of three parts:  
Opening Tag:  Indicates the beginning of an HTML element.  
Content: Represents the information that will be displayed on the webpage.  
Closing Tag:  Indicates the end of the HTML element.  
 
Example 
<h1>ABC College of Engineering</h1>  
 
Structure 
Opening Tag : <h1>  
Content : ABC College of Engineering  
Closing Tag : </h1>

heading of the webpage and displays it accordingly.  
 
Example 
A college website needs to display its name as the main heading. The developer uses:  
<h1>ABC College of Engineering</h1>  
 
The browser interprets <h1> as a heading element and displays the college name in a 
larger font, making it immediately visible to users.

complete structure formed by the opening tag, the content, and the closing tag.

main topic and its subtopics. Search engines also use headings to understand the structure 
of a webpage, making proper heading usage important for SEO.

A university website displays the university name, department name, and laboratory details.  
<h1>ABC University</h1>  
 
<h2>Department of Computer Science</h2>

11. Semantic HTML Elements  
 
11.1 Introduction  
As websites became larger and more complex, developers needed a better way to organize 
webpage content. Earlier, most webpages were designed using generic elements such as <div>, 
making it difficult to understand the purpose of different sections. HTML5 introduced 
Semantic HTML elements , which clearly describe the role of each section of a webpage. 
Semantic elements improve webpage organization, make the code easier to read, enhance 
accessibility, and help search engines understand webpage content more effectively.  
 
11.2 Semantic HTML Elements  
Definition: Semantic HTML elements are HTML elements that clearly describe the meaning 
and purpose of the content they contain.  
 
Unlike generic elements, semantic elements indicate the role of each section of a webpage. 
For example, a <header> element represents the header section, while a <footer> element 
represents the footer section.  
 
11.3 Why are Semantic HTML Elements Important?  
In earlier versions of HTML, developers commonly used <div> elements for every section 
of a webpage. Although this displayed the webpage correctly, it did not explain the purpose 
of each section.  
 
Semantic HTML elements solve this problem by giving meaningful names to different parts 
of the webpage. This improves code readability, makes website maintenance easier, supports 
screen readers for visually impaired users, and helps search engines identify  important 
content. 
 
Scenario-Based Example  
A college website contains the following sections:  
• College Logo 
• Navigation Menu  
• Department Information  
• Latest News  
• Contact Information  
 
If every section is created using only <div> elements, another developer may find it 
difficult to understand the webpage structure. By using semantic elements such as <header>, 
<nav>, <section>, and <footer>, the purpose of each section becomes immediately clear.

12.2 The <div> Tag 
Definition: The <div> (Division) tag is a block -level HTML element used to group related 
content into separate sections of a webpage.  
 
The <div> element does not provide any visual formatting by itself. It acts as a 
container that helps organize webpage content and is commonly used with CSS and 
JavaScript to style or manipulate webpage sections.  
 
Syntax 
<div> 
 
Content 
 
</div> 
 
Example 
<div> 
 
<h2>Department of Computer Science</h2>  
 
<p>Admissions are open for the academic year 2026.</p>  
 
</div> 
In this example, the heading and paragraph are grouped into a single section using the 
<div> element. 
 
Scenario-Based Example  
A college website contains separate sections for Departments, Facilities, and Placements. Each 
section can be grouped using a separate <div> element, making the webpage well -organized 
and easier to design.

12.3 The <span> Tag 
Definition: The <span> tag is an inline HTML element used to group or identify a small 
portion of text within a line.  
 
Unlike the <div> element, the <span> element does not begin on a new line. It is mainly 
used to apply different styles or identify specific words without affecting the surrounding 
text. 
 
Syntax 
<span>Content</span>  
Example 
<p>Welcome to <span>HTML Programming</span>.</p>  
 
In this example, only the words HTML Programming  are enclosed within the <span> 
element, while the remaining text continues on the same line.  
 
Scenario-Based Example  
An online shopping website displays:  
 
Price: ₹999 
The developer wants to highlight only the price without changing the remaining text. The 
<span> element is used to identify only the price so that it can be styled separately.  
 
12.4 Difference Between <div> and <span> 
Although both elements are used for grouping content, they serve different purposes.  
The <div> element is a block-level element. It always starts on a new line and generally 
groups larger sections of a webpage.  
 
The <span> element is an inline element. It remains within the same line and is used to 
group a small portion of text.  
 
Example 
<div> 
 
<h2>Student Details</h2>  
 
<p>Name: Rahul</p>  
 
</div> 
 
<p>Course: <span>B.Tech AI</span></p>  
In this example, the <div> element groups the complete student information, whereas the 
<span> element identifies only the course name within the paragraph.

13. Multimedia Elements and HTML5  
 
13.1 Introduction  
Modern websites are no longer limited to displaying only text and images. They also 
provide audio lectures, video tutorials, online meetings, animations, and interactive content. 
For example, educational websites stream video lectures, music applications p lay songs, and 
news websites publish video reports. Earlier, displaying multimedia on webpages required 
external plugins such as Adobe Flash. HTML5 simplified this process by introducing built -
in multimedia elements that allow browsers to play audio and vi deo directly without additional 
software. 
 
13.2 Multimedia in HTML  
Definition: Multimedia refers to the combination of different types of digital content, such 
as text, images, audio, video, and animations, presented together on a webpage to improve 
user interaction and learning.  
 
Multimedia makes webpages more attractive, interactive, and informative. It is widely used 
in educational portals, entertainment websites, online learning platforms, social media 
applications, and business websites.  
 
Scenario-Based Example  
An online learning platform provides recorded video lectures and audio explanations for 
students. Instead of downloading separate media players, students can watch videos and

13.3 HTML5 Multimedia Elements

most commonly used multimedia elements are <audio> and <video>.

13.6 What is HTML5?  
Definition: HTML5 is the fifth and the latest major version of HyperText Markup Language, 
developed to support modern web applications by providing improved structure, multimedia 
support, graphics, and better user interaction.  
 
HTML5 was introduced to overcome the limitations of earlier HTML versions and to support 
the growing needs of modern websites. It enables developers to create responsive and 
interactive webpages without relying on external plugins.
