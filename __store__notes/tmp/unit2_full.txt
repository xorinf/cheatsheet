1. Introduction to CSS and Types of Style Sheets  
1.1 Introduction  
In Unit–I, we learned that HTML is used to create the structure of a 
webpage by defining elements such as headings, paragraphs, tables, forms, 
and images. Although HTML organizes the content, it does not provide an 
attractive appearance. A webpage develope d using only HTML appears plain 
and lacks visual appeal.  
To improve the appearance of webpages, Cascading Style Sheets (CSS)  is 
used. CSS controls the presentation of HTML elements by defining colors, 
fonts, spacing, borders, layouts, and many other visual properties. It 
separates the content from the design, making webpages more attractive, 
consistent, and easier to maintain.  
Today, almost every modern website, such as Google, Amazon, Flipkart, or a 
college website, uses CSS to create a professional and user -friendly interface.  
 
1.2 Need for CSS

display content rather than design webpages. As websites became more 
interactive and visually appealing, developers required a separate technology to 
control the appearance of webpages.  
CSS was introduced to solve this problem by allowing developers to define 
styles separately from HTML content. Instead of applying the same 
formatting repeatedly to multiple HTML elements, CSS enables a single style 
rule to be reused throughout a website. This reduces code duplication, 
improves consistency, and simplifies website maintenance.

2.2 CSS Selectors  
Definition: A CSS selector is a pattern used to select one or more HTML 
elements on which CSS styles are applied.  
Selectors help developers target specific elements without affecting the entire 
webpage. Depending on the requirement, CSS provides different types of 
selectors such as element selectors, class selectors, ID selectors, and universal 
selectors.

Definition: An element selector selects all HTML elements of a particular 
type and applies the specified style to them.

4. CSS Box Model and Conflict Resolution  
4.1 Introduction  
Whenever an HTML element is displayed on a webpage, it occupies a certain 
amount of space. For example, a heading, paragraph, image, or button is 
not displayed randomly; each element is placed inside an invisible rectangular 
box. The browser uses this box to determine the size of the element and 
the space around it. This concept is known as the CSS Box Model . 
In addition, a webpage may contain multiple CSS rules that apply to the 
same HTML element. When different rules specify different styles for the 
same property, the browser must decide which style to apply. This process is 
called Conflict Resolution  or the CSS Cascade . Understanding these concepts 
helps developers create well -structured, consistent, and visually appealing 
webpages. 
 
4.2 CSS Box Model  
Definition: The CSS Box Model is a layout model that represents every 
HTML element as a rectangular box consisting of content, padding, border, 
and margin.  
The browser calculates the total size of an HTML element using these four 
components. A clear understanding of the Box Model is essential for 
controlling spacing, alignment, and webpage layout.  
 
4.3 Components of the CSS Box Model  
The CSS Box Model consists of four components arranged from the inside 
to the outside.  
1. Content 
Definition: The content is the actual information displayed inside an HTML 
element, such as text, images, or other HTML elements.  
It is the central part of the box where the browser displays the element's 
data. 
  FACULTY NAME:  A VINASH PAL LIDLAAN , ASSISTANT PROFESSOR, DEPT:  AI 
 
 
Example 
<p>Welcome to ABC College.</p>

Scenario-Based Example

2. Padding 
Definition: Padding is the space between the content and the border of an 
HTML element.  
Padding creates internal spacing, making the content appear less crowded.  
Example 
p{ 
    padding:20px;  
} 
The browser leaves 20 pixels of space between the paragraph text and its

3. Border

8. Scope, Arrays, Objects, DOM and Events  
8.1 Introduction  
As JavaScript programs become larger, developers need better ways to 
organize data, control where variables can be used, and respond to user 
interactions. JavaScript provides several important concepts to achieve these 
goals. Scope controls the accessibility of variables, arrays store multiple 
values in a single variable, objects represent real -world entities using 
properties, the Document Object Model (DOM)  allows JavaScript to access 
and modify HTML elements, and events enable webpages to respond to user 
actions such as clicking buttons or entering data. Together, these concepts 
help developers build interactive and well -structured web applications.  
 
8.2 Scope 
Definition: Scope is the area of a program where a variable can be accessed 
or used. 
A variable is not always available throughout the entire program. Depending 
on where it is declared, it may be accessible only within a function or 
throughout the script. Understanding scope helps prevent errors and improves 
program organization.  
 
Types of Scope  
JavaScript commonly uses two types of scope:  
• Global Scope  
• Local Scope 
 
1. Global Scope  
Definition: A global variable is declared outside all functions and can be 
accessed from anywhere in the program.  
 
  FACULTY NAME:  A VINASH PAL LIDLAAN , ASSISTANT PROFESSOR, DEPT:  AI 
 
 
Example 
let college = "ABC College";  
function display()  
{ 
    document.write(college);  
} 
display(); 
In this example, the variable college is available inside the function because 
it is declared globally.  
Scenario-Based Example  
A university website stores the university name in a global variable because 
it is displayed on every webpage.  
 
2. Local Scope 
Definition: A local variable is declared inside a function and can be accessed 
only within that function.  
Example 
function student()  
{ 
    let name = "Rahul";  
    document.write(name);  
} 
student(); 
The variable name cannot be accessed outside the student() function.

8.5 Document Object Model (DOM)  
Definition: The Document Object Model (DOM) is a programming interface 
that represents an HTML document as a tree of objects, allowing JavaScript 
to access, modify, add, or remove HTML elements dynamically.  
When a webpage is loaded, the browser creates the DOM. JavaScript uses 
the DOM to interact with webpage elements without reloading the page.

One of the most commonly used DOM methods is:  
document.getElementById("id");  
This method selects an HTML element using its id attribute. 
 
Example

The paragraph text changes without reloading the webpage.
