4.1 Introduction to TypeScript and Installation  
4.1.1 Introduction  
JavaScript is one of the main programming languages used to develop interactive web 
applications. It allows developers to create variables, functions, objects, classes, and many 
other program components. However, JavaScript is dynamically typed, which mean s that 
the type of a variable is generally determined from the value assigned to it and can 
change during program execution.  
For small programs, this flexibility is convenient. In larger applications, however, an 
incorrect type of value may produce errors that are difficult to identify.  
TypeScript was introduced to provide additional type -checking features while retaining the 
basic programming capabilities of JavaScript.  
4.1.2 TypeScript  
Definition: TypeScript is an open -source programming language developed and maintained 
by Microsoft that extends JavaScript by adding static type -checking and additional 
development features. It allows programmers to describe the expected types of variable s, 
parameters, objects, and other program elements so that many errors can be detected 
during development. TypeScript source code is normally converted into JavaScript before 
execution. It is particularly useful for developing large, structured, and mainta inable 
JavaScript applications.

4.2 Variables, Data Types and Functions  
4.2.1 Introduction  
Variables, data types, and functions are fundamental elements of TypeScript programming. 
Variables are used to store information, data types specify what kind of information 
can be stored, and functions organize reusable operations.  
TypeScript extends the familiar JavaScript syntax by allowing programmers to explicitly 
specify the expected type of a variable, function parameter, and return value. This type 
information helps the compiler identify many incorrect assignments and function  calls 
before the program is executed.  
For example, an online shopping website may store a product name as text, product 
price as a number, and product availability as a Boolean value. TypeScript allows these 
expected types to be clearly specified.  
 
4.2.2 Variables in TypeScript  
Definition: A variable is a named storage location used to hold a value that may be 
accessed and used by a program. In TypeScript, variables can be declared using 
JavaScript keywords such as let and const, and an expected data type can be 
specified using a type annota tion. TypeScript checks whether the values assigned to the 
variable are compatible with its expected type. Variables are used to represent information 
such as names, prices, quantities, marks, and status values.  
Basic Syntax

4.4 Arrow Functions  
4.4.1 Introduction  
Functions are used to organize reusable operations in TypeScript programs. In the 
previous topics, functions were written using the traditional function keyword with 
parameters and return types.  
TypeScript also supports arrow functions , which provide a shorter way of writing 
function expressions. Arrow functions are commonly used for small calculations, 
callbacks, array operations, and other short operations in web applications.  
For example, a shopping website may need a small function to calculate the total price 
of a product. 
Traditional function:  
function calculateTotal(  
    price: number, 
    quantity: number  
): number { 
    return price * quantity;  
} 
The same operation can be written using an arrow function.  
const calculateTotal = (  
    price: number, 
    quantity: number  
): number => {  
    return price * quantity;

on the properties and behaviours that a value provides rather than only on its declared 
name or origin. TypeScript more precisely uses a structural type system, meaning that 
an object can be compatible with an interface when it contains the required members 
with compatible types. The object does not necessarily need to be explicitly declared 
using that interface. This allows flexible reuse of objects that share the required 
structure. 
Note: If an object has the required structure,  TypeScript can treat it as compatible.

explicit nominal relationship between named types. This behaviour is closely related to 
what programmers commonly call duck typing.

A public member can be accessed from inside the class, child classes, and outside 
code. 
8. What is private?  
A private member can be accessed directly only within the class that declares it.  
9. What is protected?  
A protected member can be accessed within its declaring class and derived classes but 
not normally through an outside object reference.  
10. What is the difference between private and protected?  
A private member is restricted to the declaring class, whereas a protected member is

4.8.31 Important Questions  
1. What are generics in TypeScript?  
Generics allow functions, classes, interfaces, and other structures to work with different 
data types while preserving information about the actual type being used. They improve 
code reuse without giving up type safety.  
2. What is a type parameter?  
A type parameter is a placeholder for a type in a generic declaration. It is commonly 
represented using a name such as T.  
3. Give the syntax of a generic function.  
function functionName<T>( value: T): T {return value;  } 
4. Why are generics useful?  
Generics reduce repeated code because one function, interface, or class can safely work 
with different types.  
5. What is the advantage of generics over any?  
Generics preserve the relationship between the actual input and output types, while any 
removes much of the compiler's type information.  
6. What is a generic class?  
  FACULTY NAME:  A VINASH PAL LIDLAAN , ASSISTANT PROFESSOR, DEPT:  AI 
 
 
A generic class contains one or more type parameters and can therefore create objects 
that work with different specified types.  
7. What is a generic interface?  
A generic interface describes a reusable object structure containing one or more type 
parameters. 
8. What is a generic constraint?  
A generic constraint restricts which types may be used with a generic type parameter.  
9. Which keyword is commonly used for a generic constraint?  
The extends keyword.  
10. What does T extends HasLength mean?  
It means that the actual type used for T must satisfy the structure required by 
HasLength. 
 
4.8.32 Summary  
Generics provide a reusable and type -safe way of working with different data types in 
TypeScript. 
A generic type parameter is commonly represented using:  
<T> 
For example: 
function returnValue<T>(  
    value: T 
): T { 
    return value; 
} 
The same function can work with strings, numbers, and other suitable types while 
preserving type information.  
Generic interfaces and classes extend the same idea to reusable object structures and 
classes.
